#   Desafio: Cadastro de Funcionários 


Leia um número inteiro N, representando a quantidade de funcionários.

Para cada funcionário, leia os seguintes dados:

id (identificador único)

nome

salário

Importante: O id de cada funcionário deve ser único, ou seja, não pode haver repetições.


Após o cadastro dos funcionários, o programa deve permitir realizar um aumento de X por cento no salário de um funcionário específico. Para isso:

Leia o id do funcionário e o valor percentual X.
Se o id informado não existir, exiba uma mensagem de erro e cancele a operação.
Listagem final
Exiba a listagem atualizada de todos os funcionários, com seus respectivos salários.
